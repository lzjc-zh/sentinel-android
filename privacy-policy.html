概述

哨兵是一款 AI API 用量监控工具，帮助用户追踪 DeepSeek 和 MiMo 平台的 Token 消耗、余额和费用。本隐私政策说明应用如何处理您的数据。

📋 数据收集

本应用收集以下数据，所有数据仅存储在您的设备本地，不会上传到任何第三方服务器：

  • API Key DeepSeek API 密钥，用于调用 DeepSeek 用量查询接口
  • User Token DeepSeek 用户令牌，用于查询详细用量数据
  • Cookie MiMo 平台认证 Cookie，用于查询 MiMo 用量数据
  • 用量数据 Token 消耗记录、余额信息、请求次数等统计数据

🔐 数据使用

  • API Key 和 Token 仅用于调用对应平台的官方 API 查询用量信息
  • Cookie 仅用于访问 MiMo 平台的用量统计数据
  • 用量数据仅在本应用内展示，用于费用追踪和趋势分析
  • 应用不会将任何数据发送到开发者或其他第三方服务器

💾 数据存储

  • 所有数据存储在应用本地数据库（Room）和偏好设置（SharedPreferences / DataStore）中
  • 数据不会备份到云端
  • 卸载应用将删除所有本地数据

🌐 网络访问

应用访问以下第三方服务：

  • DeepSeek API（api.deepseek.com）— 查询用量和余额
  • MiMo API（platform.xiaomimimo.com）— 查询用量和余额

网络访问仅用于上述数据查询，不涉及广告、分析或数据上报。

👤 第三方服务

本应用不集成任何第三方 SDK、广告平台、数据分析服务或追踪工具。

👶 儿童隐私

本应用不面向 14 岁以下儿童，不会故意收集儿童个人信息。

📝 权限说明

  • 网络访问（INTERNET）：用于调用 DeepSeek / MiMo API 查询用量数据
  • 网络状态（ACCESS_NETWORK_STATE）：检测网络连接状态
